Tokens

css/love.tokens.css

Overview

Tokens are CSS custom properties that hold every visual value in Love.css. No component hardcodes a color, radius, or spacing. Change a token and every place that uses it updates.

Three levels

Level Purpose Example
Primitives Raw values, never change per theme. --love-color-grape-600
Semantic Roles. Change between themes. --love-bg, --love-text
Component Specific to one component. --love-btn-radius

How to override

Put your rules in love.overrides.css. It loads last, so your values win without !important.

:root {
  --love-primary: oklch(0.55 0.20 300);
  --love-btn-radius: 0;
  --love-card-padding: var(--love-space-8);
}

Spacing scale

Based on 0.25rem increments. Every gap, padding, and margin in the framework comes from here.

Token Value Pixels
--love-space-10.25rem4px
--love-space-20.5rem8px
--love-space-41rem16px
--love-space-61.5rem24px
--love-space-82rem32px

Anatomy

Why oklch

Colors use oklch() instead of hex or rgb. Oklch is perceptually uniform: a change of 0.1 in lightness looks the same at any hue. This makes light/dark theme swaps trivial.

Why three levels

Primitives give you a palette. Semantics give you roles. Components give you control points. Three levels let you change one thing without touching the rest.

Themes

css/love.themes.css

Overview

Three themes: light, dark, and high-contrast. Themes only redefine semantic tokens. No component changes.

Activating

<html data-love-theme="dark">
Value Result
lightLight background, dark text.
darkDark background, light text.
high-contrastPure black on white, black borders.
(no attribute)Follows prefers-color-scheme.

Anatomy

Why color-scheme

Native form controls — <select>, <input type="date">, scrollbars — are drawn by the browser. Setting color-scheme: dark tells the browser to use its dark palette. Without it, they stay bright white inside a dark page.

Notes

  • Theme tokens are declared on :root, [data-love-theme], and inside a prefers-color-scheme media query. Three ways to resolve — always check all three if a color looks wrong.
  • To add a custom theme, create [data-love-theme="sepia"] in love.overrides.css and override the same tokens.

Fonts

css/love.fonts.css

Overview

Space Grotesk, a variable font by Florian Karsten, under SIL Open Font License 1.1. One file covers all weights from 300 to 700.

Replacing the font

  1. Drop your font files into assets/fonts/YourFont/.
  2. Add an @font-face block to css/love.fonts.css.
  3. Update --love-font-sans in love.tokens.css.

Why font-display: swap

Without it, the browser shows blank text for up to three seconds. With swap, it renders the fallback font immediately and swaps when ready.

Reset

css/love.reset.css

Overview

Combines normalize.css v8 with Eric Meyer's reset. Fixes cross-browser inconsistencies and removes default margins and paddings, so every browser starts from the same baseline.

What it does

  • box-sizing: border-box globally.
  • Removes all margins and paddings.
  • Images responsive by default with max-width: 100%.
  • Removes link decoration and color (styling is base.css).
  • Normalizes form controls across browsers.

Base

css/love.base.css

Overview

Base styles every bare HTML element. No classes required. Headings, paragraphs, lists, blockquotes, code, tables, figures — all get sensible defaults from tokens.

What gets styled

Element Default styling
h1–h6Semibold, tight line-height, growing top margin.
pBottom margin of space-4.
aPrimary color, underline on hover, grape for :visited.
ul, olRestored markers, left padding.
code, preMonospace, subtle background.
blockquoteLeft border, muted, italic.
::selectionGrape background, white text.

Notes

  • base.css targets elements, not classes. For one-off changes, use a class in overrides, not a new base rule.
  • The prefers-reduced-motion block at the bottom disables all animations globally, including anything you add in overrides.

Animations

css/love.animations.css

Overview

Simple CSS animations only. Entrance effects, spinners, shimmer. Anything requiring JS orchestration, scroll-driven timelines, or physics is outside Love.css.

Available classes

Class Effect
.fade-inOpacity 0 to 1.
.fade-outOpacity 1 to 0.
.slide-upSlides up with fade-in.
.slide-downSlides down with fade-in.
.scale-inScales from 0.95.
.spinContinuous rotation.
.shimmerGradient sweep.
.pulseOpacity oscillation.

Only transform and opacity

Every keyframe animates only transform and opacity. These are handled by the compositor thread, so animations stay smooth even when JS is busy.

Overrides

css/love.overrides.css

Overview

Empty file that loads after every other module. Put customizations here. They win without !important. When you upgrade Love.css, this file is not touched.

What to put here

  • Token overrides: --love-primary, --love-btn-radius, --love-font-sans.
  • New themes: [data-love-theme="sepia"] with your own tokens.
  • Project-specific components built on top of Love.css primitives.
  • Small patches when a framework default does not fit.
:root {
  --love-btn-radius: 0;
  --love-primary: oklch(0.55 0.20 300);
}

[data-love-theme="sepia"] {
  --love-bg: #f4ecd8;
  --love-text: #3a2f1c;
  --love-border: #d6c8a8;
}

Notes

  • If you upgrade and something breaks, this file is the first place to check.
  • If you find yourself overriding the same thing three times, open an issue instead.
