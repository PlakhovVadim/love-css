    Accordions

    Basic accordion

    What is Love.css?

    Love.css is a minimalist CSS framework for fast interface assembly. It focuses on design, not animations, and gives you full control through tokens.

    How do I install it?

    Clone the repository, run the installer, and start using classes. No build step, no dependencies, no configuration files.

    Can I customize it?

    Yes. Every visual parameter is a CSS variable. Change a token and the entire framework adapts. Or use love.overrides.css for your own rules.
