Document metadata

<base>

The base element specifies the base URL for all relative URLs in a document. It must appear before any element that uses a URL.

<link>

The link element defines relationships between the current document and external resources. Most commonly used for stylesheets and icons.

<meta>

The meta element represents metadata that cannot be expressed by other meta-related elements.

<style>

The style element contains CSS rules for the document.

<title>

The title element defines the document's title, shown in the browser's title bar or tab.

The aside element represents a portion of a document whose content is only indirectly related to the document's main content. Asides are frequently presented as sidebars or call-out boxes.
